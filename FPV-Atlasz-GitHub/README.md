# FPV Atlasz

Magyar FPV-tanulófelület a Seeker 3, a RadioMaster Pocket és a Liftoff mellé. Az oldal statikus HTML-, CSS- és JavaScript-fájlokból áll. Külön alkalmazásszerver, telepítés és ChatGPT-bejelentkezés nélkül használható.

## Helyi indítás

A kicsomagolt könyvtárban futtasd a `python -m http.server 8000` parancsot, majd nyisd meg a http://localhost:8000 címet. A tananyag a helyi fájlokban van. A hivatkozott videókhoz és külső forrásokhoz internetkapcsolat szükséges.

## GitHub Pages

A könyvtár tartalmát tedd a repository gyökerébe, úgy, hogy az index.html közvetlenül a main ágon legyen. A repository Settings → Pages részén válaszd a Deploy from a branch lehetőséget, a main ágat és a /(root) mappát. A publikálás után ugyanitt jelenik meg az élő cím.

## Meglévő haladás átvitele

A korábbi oldalon nyisd meg az Adatmentés menüt, és töltsd le a mentési fájlt. Az új címen ugyanitt válaszd a visszaállítást. Az edzések és a tudásszintek böngészőnként és webcímenként külön tárolódnak. A mentési JSON-t tartsd magadnál.
